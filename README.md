# GTINCode

調剤在庫マスタ／ヒート GTIN カード印刷ブックを自動生成する Excel VBA マクロ集です。

白紙のブックでマクロを実行すると、4 枚のシート（データ／命名規則／バーコード計算／カード印刷）を一括生成します。

## 構成

| ファイル | 内容 |
|---|---|
| `mdlBuild.bas` | ブック生成マクロ本体（`BuildWorkbook`）。4 シートのレイアウトと数式を構築します。 |
| `mdlImport.bas` | ヒート画像の一括配置マクロ（`ImportHeatImages`）。データシート L 列のパスから画像を読み込み、カード印刷シートに配置します。 |

## セットアップ

1. Excel で新規ブック（白紙）を作成します。
2. `Alt` + `F11` で VBE を開きます。
3. 「ファイル」→「ファイルのインポート」で `mdlBuild.bas` と `mdlImport.bas` を取り込みます。
   （または「挿入」→「標準モジュール」に内容を貼り付けます）
4. ブックを **マクロ有効ブック（.xlsm）** として保存します。

## 使い方

### 1. ブックの生成

`Alt` + `F8` から `BuildWorkbook` を実行します。既存の 4 シートがある場合は削除してから再生成されるため、何度でも実行できます。

生成後、「データ」シートの C 列にヒートの GTIN 14 桁を入力してください。

### 2. ヒート画像の配置（任意）

「データ」シートの L 列に画像のフルパスを入力したうえで、`ImportHeatImages` を実行します。カード印刷シートの画像枠にアスペクト比を保ったまま中央配置されます。こちらも再実行可能です。

## レイアウト定数

`mdlBuild.bas` 冒頭の `Public Const` でカードのレイアウトを調整できます。

| 定数 | 既定値 | 意味 |
|---|---|---|
| `N_ITEMS` | 20 | 品目数 |
| `CARD_W` | 129 | カード幅（列数）= 45.5mm |
| `CARD_H` | 26 | カード高さ（行数） |
| `COLS_N` | 4 | 横に並べる枚数 |
| `GAP_R` | 4 | 段間の行数 |
| `START_C` / `START_R` | 2 / 2 | 開始列・開始行 |
| `BC_OFS` | 17 | バーコード左オフセット |

## 動作環境

- Microsoft Excel（Windows 版、VBA 有効）
